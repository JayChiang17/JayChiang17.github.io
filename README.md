# 棒球人生 ⚾

從高中開始，經歷逐順位選秀、旅外、合約談判、自由市場、家庭與財務抉擇，直到引退。玩家控制選擇與準備，結果由每一次現場擲骰決定。

## 遊戲特色

* **即時骰子**：完全隨機模式每次都重新產生結果；同種子挑戰可和朋友比較不同選擇。
* **有張力的判定**：只顯示「略有把握／勝負難料／風險偏高」等情勢提示；重大抉擇才進入可逐格停下的拉霸。
* **99 制能力**：綜合與各項能力滿分 99，主畫面持續顯示目前值與球探潛力；永久成長以季初訓練為核心。
* **高中球季計畫**：每季六個隨機方案會明列大賽晉級戰力、上場競爭、傷病、訓練、球探及團隊影響，並提供八強與四強估算。
* **隨機老化**：年齡、守位、負荷與傷病史改變老化風險；續戰決定前會先列出完整退化結果。老將訓練骰逐年減少，體力與其他身體工具也有高齡成本、年度恢復上限或逆齡鎖定。
* **年輕球員養成保護**：19 歲職業新秀有 2 季、20～21 歲有 1 季養成觀察；單季低迷會先縮減角色並留在二軍／小聯盟，連續未改善、合約到期或紀律問題才進入釋出審查。
* **投手負荷規劃**：開季直接比較全力投、普通投與養生球對平均球速、ERA、三振、球季評價及手肘負荷的實際修正，並顯示季末負荷預估。
* **選秀直播**：六隊、十輪逐順位唱名，其他新秀由姓名產生器建立，可逐一觀看、自動播放或跳到結果。
* **完整大聯盟**：收錄 MLB 30 隊與六分區，加入球場、天候、客場移動、教練與隊友化學效應。
* **46 種隱藏特性**：王牌、火球、控球、重砲、跑壘、守備、季後賽、家庭與財務特性由連續球季數據和實際選擇形成；聲望只做長期小幅影響。
* **隨機人物**：選秀新秀、台日美職隊友與球迷都由各地姓氏／姓名庫即時生成，每段人生遇到的人不同。
* **合約與財務**：固定年薪、保障比例、反提案、FA／挖角市場與稅費；盜壘及守備也會成為有限度的談判籌碼。可用現金、投資、房產、負債及淨資產分開計算，花費可以真的耗盡現金。
* **球季動畫**：Three.js 集中用於訓練、重大名單／合約事件與生涯里程碑；逐月賽季模擬可暫停、切換 1／2／4 倍速或直接完成。
* **固定播報台**：桌面採固定三欄，中央生涯播報是唯一主視覺；年度時間軸分類顯示賽事、健康、名單合約、榮譽及場外人生，兩側維持低對比輔助資訊。
* **賽季總結**：每季結束必定彈出球隊、層級、角色與核心數據；投手顯示完整投球數據，野手另有守備率、失誤、雙殺／助殺／阻殺與守備貢獻。捕手另列配球能力、評級、投手群 ERA 影響與配球防失分。
* **生涯資料中心**：生涯中隨時查看跨聯盟累積、逐年成績、分類獎項、球隊軌跡及完整合約財務，不需要等到引退結算。
* **手機四分頁**：手機固定提供播報、球員、本季、財務四個入口，資訊不再全部堆成長頁；選擇使用大型決策面板且所有後果都會寫回播報。
* **全螢幕結算圖**：引退後一鍵產生完整生涯圖，以滿版檢視器閱讀全部年表，並可分享或下載原尺寸 PNG。
* **手機能力分配**：加點按鈕使用 66px 觸控高度；點數用完後全部鎖定變灰，並固定顯示復原與確認操作。
* **生涯挑戰**：高能力成長成本、職業訓練量、大賽點數與升級名額都經過收緊，天賦只能提高機會，不能保證成功。
* **二軍生存競爭**：中職二軍會依連續實績、能力、年齡與傷病進行留用審查；長期打不起來會被釋出，只能尋找測試約、轉業餘或引退。
* **一軍動態名單**：中職、日職與大聯盟都會依一軍實際 ERA、WHIP、OPS、出賽樣本、年齡及球隊戰績進行季末審查；低於聯盟留用線可能降至二軍／3A，極差成績直接失去席位。
* **MLB 40 人名單制度**：升上 MLB 會正式選入 40 人名單；下放依小聯盟選擇權球季與單季 option 次數處理。選擇權用完後必須經 DFA、七日處理期、交易／claim／outright／release 流程，並依 3 年、5 年及 10-and-5 年資提供拒絕權與合約保障。
* **能力連動數據**：投手能力分別驅動平均球速（最高 105 mph）、三振、保送、ERA、WHIP、出賽與局數；頂尖球員在稀有生涯年可能打出真實世界尺度的極端成績。
* **非固定行程**：每季可能完全平靜，也可能抽到 1–5 段事件；隊友、家庭與球迷活動不再年年照同一套流程。事件庫超過 130 種，並加入台、日、美職官方紀錄改編案例與來源連結。
* **聯盟年度會報**：球季總結同步產生完整分區戰績、勝敗、勝率、勝差、季後賽與冠軍；自由市場依球隊戰績、補強方向、守位需求與預算產生報價。
* **情境一致**：主場、層級、聯盟移動、教練團、上季表現與更衣室關係共同決定球季環境，交易流言不再無條件亂出現。
* **完整獎項**：加入單月獎、數據王、年度第一隊、後援獎、銀棒／最佳九人、金手套、MVP、公益與隊友票選獎；競爭線逐季浮動，並依守位顯示真正相關的數據。
* **公平訓練骰**：每顆骰子彼此獨立，1～6 各為 1/6；天賦只提高最低成果，不提高原始擲出 6 的機率。

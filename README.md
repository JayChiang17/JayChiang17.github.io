# 棒球人生 ⚾

從高中開始，經歷逐順位選秀、旅外、合約談判、自由市場、家庭與財務抉擇，直到引退。玩家控制選擇與準備，結果由每一次現場擲骰決定。

## 遊戲特色

* **即時骰子**：完全隨機模式每次都重新產生結果；同種子挑戰可和朋友比較不同選擇。
* **有張力的判定**：只顯示「略有把握／勝負難料／風險偏高」等情勢提示；重大抉擇才進入可逐格停下的拉霸。
* **99 制能力**：綜合與各項能力滿分 99，主畫面持續顯示目前值與球探潛力；永久成長以季初訓練為核心。
* **隨機老化**：年齡、守位、負荷與傷病史改變老化風險，每年重新擲骰，不再固定全能力一起下降。
* **選秀直播**：六隊、十輪逐順位唱名，其他新秀由姓名產生器建立，可逐一觀看、自動播放或跳到結果。
* **完整大聯盟**：收錄 MLB 30 隊與六分區，加入球場、天候、客場移動、教練與隊友化學效應。
* **動態特性與聲望**：王牌、重砲、上壘、守備與穩定型特性由連續球季數據形成，也會隨低潮消失；聲望改為長期小幅累積，影響力不再蓋過能力與實績。
* **隨機人物**：選秀新秀、台日美職隊友與球迷都由各地姓氏／姓名庫即時生成，每段人生遇到的人不同。
* **合約與財務**：固定合約年薪、保障比例、反提案、FA 市場、稅負／經紀人費、生活／家庭／奢侈支出與淨資產。
* **球季動畫**：Three.js 立體骰子、可逐格點停的拉霸、逐月賽季模擬與年度大賽成績卡。
* **固定播報台**：桌面上方、左右資料欄與下方選項維持固定尺寸，新增故事時只捲動中央生涯播報；兩側改為低對比輔助資訊。
* **賽季總結**：每季結束必定彈出球隊、層級、角色與核心數據；投手完整顯示出賽、局數、勝敗、中繼／救援、三振、保送、ERA 與 WHIP。
* **生涯挑戰**：高能力成長成本、職業訓練量、大賽點數與升級名額都經過收緊，天賦只能提高機會，不能保證成功。
* **能力連動數據**：投手的球速、控球、變化球與體力分別驅動三振、保送、ERA、WHIP、出賽與局數。
* **非固定行程**：每季可能完全平靜，也可能抽到 1–5 段事件；隊友、家庭與球迷活動不再年年照同一套流程。事件庫超過 130 種，並加入台、日、美職官方紀錄改編案例與來源連結。
* **聯盟年度會報**：球季總結同步產生完整分區戰績、勝敗、勝率、勝差、季後賽與冠軍；自由市場依球隊戰績、補強方向、守位需求與預算產生報價。
* **情境一致**：主場、層級、聯盟移動、教練團、上季表現與更衣室關係共同決定球季環境，交易流言不再無條件亂出現。
* **完整獎項**：加入單月獎、數據王、年度第一隊、後援獎、銀棒／最佳九人、金手套、MVP、公益與隊友票選獎。
* **稀有高點**：每顆訓練骰獨立，最高 6 點的機率約 5%；天賦只提高最低成果，不提高抽中最高點的機率。
